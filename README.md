## What is NexSite?

One HTML file. Hosted on GitHub Pages. Edit everything from your phone browser — no app, no server, no coding needed.

**Live site:** [nexdeve.github.io/nexsite](https://nexdeve.github.io/nexsite)

---

## Features

- Edit from **your phone browser** — no app needed
- Password protected — only you can edit
- **8 section types:** Hero, About, Services, Portfolio, Skills, Contact, Text, Custom HTML
- **Design editor** — change colors instantly
- **Domain support** — use your own domain (nexdeve.com)
- All data saved locally in your browser
- 100% free — GitHub Pages hosting

---

## How to Use

### 1. Open the site on your phone
```
https://nexdeve.github.io/nexsite
```

### 2. Tap the lock icon (🔒) bottom right
Default password: `nexdeve2026`

### 3. Edit bar appears at the bottom
- **Sections** — add/edit/reorder sections
- **Design** — change colors
- **Settings** — site title, SEO, change password
- **Domain** — configure custom domain

### 4. Save — done!

---

## Use Your Own Domain (nexdeve.com)

1. Go to your domain registrar (Namecheap, GoDaddy, etc.)
2. Add CNAME record: `www` → `nexdeve.github.io`
3. Create file named `CNAME` in this repo with content: `nexdeve.com`
4. Go to repo Settings → Pages → enter your domain

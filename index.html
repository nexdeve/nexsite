To use a custom domain:
STEP 1 — Go to your domain registrar (Namecheap, GoDaddy, etc.)
Add a CNAME record:
Type: CNAME
Host: www (or @)
Value: nexdeve.github.io
STEP 2 — Create CNAME file in your repo
File name: CNAME (no extension)
File content: your domain (e.g. nexdeve.com)
STEP 3 — GitHub Repo Settings
Go to: github.com/nexdeve/nexsite → Settings → Pages
Enter your domain in "Custom domain" field → Save
